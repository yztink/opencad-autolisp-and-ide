OpenCAD LISP UI Tutorials

Build an interactive coordinate-entry tool that collects points into a table and draws connected lines or circles in a chosen color.

Tutorial 1

Side Panel (Dockable)

Create a persistent dockable panel using oc-panel-register, button action expressions, oc-panel-get, and oc-panel-update.

 Tutorial 2

Modal Dialog (Reactive)

Create a modal dialog using oc-dialog, oc-dialog-show, and an on-dialog-action callback to update the table live before drawing.

What Both Tutorials Build

FeatureControls UsedBehavior
Coordinate Inputoc-number + oc-buttonEnter X and Y values and append them to the points table.
Point Listoc-tableDisplays (X, Y) rows with add/delete support.
Optionsoc-choiceSelect a drawing color and entity type (Lines or Circles).
Draw Entitiescommand + CECOLORLines: connects P1→P2, P2→P3… Circles: places a circle at each point.
