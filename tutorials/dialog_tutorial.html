Tutorial 2: Programming a Modal Dialog

This tutorial builds the exact same coordinate-drawing tool as a reactive modal dialog using oc-dialog, oc-dialog-show, and an on-dialog-action callback.

Step 1: Define the Local Action Callback

Inside c:coorddialog, define a local on-dialog-action function taking (id action values). When the user clicks Add Point (btn_add), read num_x, num_y, and tbl_pts from values with oc-get, and return an association list of updated controls.

(defun on-dialog-action (id action values / x y tbl new-row new-tbl)
  (cond
    ((= id "btn_add")
     (setq x   (oc-get "num_x" values))
     (setq y   (oc-get "num_y" values))
     (setq tbl (oc-get "tbl_pts" values))
     (if (not tbl) (setq tbl '()))

     (setq new-row (list (rtos (if x x 0.0) 2 4) (rtos (if y y 0.0) 2 4)))
     (setq new-tbl (append tbl (list new-row)))

     (list
       (cons "tbl_pts" new-tbl)
       (cons "lbl_status" (strcat "Points in table: " (itoa (length new-tbl))))
     ))

    (T nil)
  )
)
Notice the difference from Side Panels: In a modal dialog, leaving action off (oc-button "btn_add" "Add Point") automatically routes the click into on-dialog-action with the full values alist. Returning a (cons key val) list updates the dialog in-place.

Step 2: Build and Show the Dialog

Use (submit . "Draw Entities") in oc-dialog options so the dialog's primary button closes the dialog and returns all control values in res.

(setq dlg
  (oc-dialog "Coordinate Drawer"
    '((width . 420.0) (submit . "Draw Entities") (cancel . "Cancel"))

    (oc-info "lbl_status" "Enter X, Y and click Add Point.")

    (oc-row
      (oc-number "num_x" "X" 0.0)
      (oc-number "num_y" "Y" 0.0)
      (oc-button "btn_add" "Add Point")
    )

    (oc-table "tbl_pts" "Coordinates"
      '("X" "Y")
      '()
      '((allow_add . T) (allow_delete . T))
    )

    (oc-row
      (oc-choice "cmb_color" "Color" '("Red" "Yellow" "Green" "Cyan" "Blue" "White") "Red")
      (oc-choice "cmb_type" "Entity Type" '("Lines" "Circles") "Lines")
    )
  )
)

(setq res (oc-dialog-show dlg 'on-dialog-action))

Step 3: Draw Entities on Submit

When the user clicks Draw Entities, oc-dialog-show returns res (or nil if cancelled). Extract tbl_pts, cmb_color, and cmb_type from res and draw the geometry.

(defun c:coorddialog (/ dlg res on-dialog-action rows pts col etype old-col i p1 p2)
  ;; (1) Define on-dialog-action from Step 1 here
  ;; (2) Build dlg and call (setq res (oc-dialog-show dlg 'on-dialog-action)) from Step 2

  (if res
    (progn
      (setq rows  (oc-get "tbl_pts" res))
      (setq col   (oc-get "cmb_color" res))
      (setq etype (oc-get "cmb_type" res))

      (setq pts '())
      (foreach r (if rows rows '())
        (if (>= (length r) 2)
          (setq pts (append pts (list (list (atof (nth 0 r)) (atof (nth 1 r)) 0.0))))
        )
      )

      (if pts
        (progn
          (setq old-col (getvar "CECOLOR"))
          (setvar "CECOLOR" (strcase (if col col "Red")))

          (cond
            ((= etype "Lines")
             (setq i 0)
             (while (< (1+ i) (length pts))
               (setq p1 (nth i pts))
               (setq p2 (nth (1+ i) pts))
               (command "_.LINE" p1 p2 "")
               (setq i (1+ i))
             ))
            ((= etype "Circles")
             (foreach p1 pts
               (command "_.CIRCLE" p1 2.5)
             ))
          )

          (setvar "CECOLOR" old-col)
          (princ (strcat "\nDrew " etype " in " col "."))
        )
        (princ "\nNo points in table.")
      )
    )
    (princ "\nCancelled.")
  )
  (princ)
)

How to Run

Save the complete c:coorddialog function (with Steps 1 and 2 placed inside it) to coord_dialog.lsp, load it with APPLOAD, and run COORDDIALOG.
